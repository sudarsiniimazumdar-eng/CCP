# Curiosity Cabinet

## Concept

An interactive 3D portfolio presented as a surreal personal curiosity cabinet.

The cabinet contains objects representing different parts of my work and thinking.

Perfume bottles represent projects.

Other objects represent:
- skills
- process
- experiments
- ideas
- about me

The visitor should feel like they are exploring someone's physical collection of ideas.

## Main Interaction

The visitor explores the cabinet.

Objects can be selected.

Perfume bottles can be inspected and interacted with.

Selecting a project bottle reveals information about the project.

The interaction should feel tactile and physical rather than like a normal portfolio website.

## Main Sections

- Work

- Ideas
- About
- Contact

## Visual Direction

The environment should feel:

- tactile
- surreal
- curious
- slightly mysterious
- handmade
- imperfect
- sophisticated
- atmospheric
- memorable

## Avoid

- generic futuristic 3D portfolio
- neon cyberpunk
- excessive glow
- generic glassmorphism
- floating gradient blobs
- corporate SaaS aesthetics
- unnecessary particle effects

## Technical Priorities

1. Performance
2. Smooth interaction
3. Responsive design
4. Mobile usability
5. Accessibility
6. Maintainable code
7. Visual quality
